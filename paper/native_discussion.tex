Парные доверительные интервалы рассчитаны методом бутстрепа по 40 фразам (10\,000 выборок); пять реализаций каждой фразы сохранялись в одном блоке. 95\%-е интервалы снижения CER относительно базового режима равны [5,15; 7,80] п.\,п. для Char4 и [6,11; 8,31] п.\,п. для KenLM. Разность CER между Char4 и KenLM составляет 0,78 п.\,п. с интервалом [-0,21; 1,74] п.\,п. Таким образом, снижение ошибки относительно равномерного распределения статистически подтверждается для обеих моделей; различие между ними по CER не достигает значимости на уровне 5\%.
