## Описание работы

Работа посвящена созданию единой конфигурируемой программной системы ЭЭГ-спеллера, поддерживающей две самостоятельные парадигмы предъявления символов и интегрированной с большой языковой моделью (БЯМ) для исправления ошибок, предсказания текста и генерации подсказок. Отдельное внимание уделяется разработке воспроизводимой методологии оценки эффективности системы в офлайн- и онлайн-режимах, включая бенчмарк для сравнения алгоритмов декодирования ЭЭГ. Проводится экспериментальная проверка с участием не менее 10–20 человек, оцениваются точность классификации P300 (≥80%), скорость ввода (≥5 символов/мин без БЯМ и ≥6 с БЯМ), прирост скорости за счёт БЯМ (≥20%), качество восстановления и предсказания текста, а также временные характеристики аудиовоспроизведения (≤300 мс).
